Open Source & Web Apps

Software & Tools

Interactive structural analysis applications, computer tools, and libraries developed for civil engineering applications and research.

FeView

A finite element model (FEM) visualization and post-processing tool developed specifically for OpenSees. Intuitive interface to visualize structural models, mode shapes, and response outputs.

Frame Analyzer

An interactive computational web tool for the linear and non-linear structural analysis of 2D frame structures subjected to various static and lateral loads.

Browse / Run

Truss Analyzer

A lightweight, fast application for calculating internal axial forces, support reactions, and nodal displacements in planar truss systems using the stiffness method.

MDoF Systems

Analytical application for evaluating the dynamic response, natural frequencies, and mode shapes of Multi-Degree of Freedom structural systems under seismic excitations.
